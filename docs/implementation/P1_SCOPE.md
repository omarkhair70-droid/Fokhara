# P1 — Become the Maker

Branch: `prototype/p1-become-maker`

P1 proves the participation half of Fokhara:

- Workshops discovery is separate from Shop.
- Workshop cards lead with action/process rather than SKU logic.
- Workshop Detail moves through:
  - observe
  - understand
  - choose
  - commit
- Booking is truthful request-mode UX.
- Recurring studio windows are not presented as live seat availability.
- The prototype stops before fake backend confirmation or payment.
- Workshop browse state is restored on return.

Fixture facts are based on current public Fokhara listings and must be revalidated before production.
