# VP1 — Photography & Image Direction

**Phase:** Authored Visual Production  
**Status:** CLOSED — photography grammar established  
**Branch:** `visual/vp1-photography-direction`

VP1 translates VP0 asset truth into an authored Fokhara image system.

This is not a moodboard of pottery photographs.

The goal is to decide how a Fokhara image behaves:

`light → distance → crop → surface → human presence → sequence → motion role`

---

## 1. Research basis

VP1 deliberately avoided award-site references.

The targeted photography research focused on:

- museum object photography
- ceramic catalog photography
- directional / raking light
- pottery process documentation
- hands and making
- still life
- glaze macro

### Reference lessons extracted

#### Museum / collection photography

Useful lesson:
- neutral fields preserve object colour;
- diffused light records shape accurately;
- controlled shadow can reveal curvature;
- raking light reveals surface detail and topography.

We borrow the **truth discipline**, not museum page composition.

#### Pottery process photography

Useful lesson:
- the most informative process frame is often the point of contact;
- hands, wet clay and the active wheel can carry more meaning than a posed portrait;
- process mess is evidence, not something to clean out of the image.

#### Ceramic still life

Useful lesson:
- functional ceramics become more convincing when shown in relationship to other objects, scale and shadow;
- negative space is useful for both visual tension and typography;
- props must never overwhelm the ceramic object.

#### Glaze macro

Useful lesson:
- colour can emerge from a real surface event;
- the glaze surface can legitimately become an abstract field without inventing a graphic texture.

# 2. Fokhara image modes

Fokhara will use **five distinct photography modes**.

They are not interchangeable filters.

## MODE A — OBJECT TRUTH

Purpose:
- identify the real product
- preserve shape and glaze colour
- support commerce decisions

Visual behavior:
- neutral or quiet field
- clean silhouette
- controlled soft light
- minimal competing props
- colour accuracy prioritized over drama
- enough shadow to retain volume

Use:
- Shop
- Product evaluation
- Cart
- collection inventory

Primary current source:
- Woo product imagery

Rule:

> Commerce must never make the user guess what the real object looks like.

---

## MODE B — MATERIAL EVIDENCE

Purpose:
- make glaze, clay and surface behave as material rather than decoration

Visual behavior:
- macro / extreme close crop
- raking or directional light
- texture and reflectivity visible
- identity may become partially abstract
- no fake texture overlay

Use:
- Home thresholds
- Collections
- Product Detail
- transitions
- Studio process

Rule:

> If the image becomes abstract, it must still be a photograph of real material.

---

## MODE C — ACTION / HAND

Purpose:
- reveal intervention
- show pressure, support, centering, cutting, glazing

Visual behavior:
- crop around the active contact point
- hands and material dominate
- tools remain when causally relevant
- clay mess and water traces stay
- face is optional and secondary
- avoid staged “craft lifestyle” posing

Use:
- Workshops
- Home maker path
- Studio
- process transitions

Rule:

> Frame the cause, not the generic workshop atmosphere.

---

## MODE D — HUMAN / LIFE

Purpose:
- prove participation, scale, use and community

Visual behavior:
- medium human context
- real activity
- object or process still remains visible
- natural body position
- no generic smiling-at-camera hero
- warm environment can exist without applying a warm filter to everything

Use:
- Workshops
- Studio
- testimonials/community
- object-in-use moments

Rule:

> People appear because they are making, holding, teaching or using.

---

## MODE E — STUDIO FIELD

Purpose:
- locate the practice in a physical world

Visual behavior:
- wide spatial frame
- shelves, tools, wheels, traces of work
- useful clutter is retained
- space should not be over-styled into a luxury showroom
- architecture is secondary to evidence of practice

Use:
- Studio
- Visit
- Home proof
- route transitions into physical place

Rule:

> The studio should look worked in, not rendered.

---

# 3. Image distance scale

Instead of treating every image as “large” or “small”, Fokhara uses a semantic distance system.

## M0 — MATERIAL

Extreme crop.

Shows:
- glaze flow
- clay grain
- fingerprint / pressure trace
- wet/dry boundary
- tool mark

Meaning:
**matter**

## M1 — ACTION

Close process crop.

Shows:
- hands + material
- tool + material
- wheel + pressure point

Meaning:
**intervention**

## M2 — OBJECT

Whole or nearly whole ceramic.

Shows:
- silhouette
- proportion
- glaze
- functional opening / handle / foot where relevant

Meaning:
**form**

## M3 — HUMAN

Person plus action/object.

Shows:
- maker
- participant
- use
- teaching
- scale

Meaning:
**participation**

## M4 — FIELD

Studio / room / arrival.

Shows:
- context
- accumulated work
- location

Meaning:
**place**

---

# 4. Core visual sequence

The original research proposed:

`material → partial form → complete object → object in use`

VP1 makes that operational.

### Object-side canonical progression

`M0 material → M2 object → M3 use`

### Maker-side canonical progression

`M1 action → M3 participant → M2 outcome`

### Studio-side canonical progression

`M4 place → M1 action → M3 teacher/maker → M2 result`

These are not mandatory page templates.

They are sequence grammars.

---

# 5. Route choreography

## Home

Primary image rhythm:

1. **M0 / M1** unresolved material or action
2. **M2** selected real object
3. **M1 / M3** maker path
4. **M4** studio proof
5. **M3** life / participation

Home should move from ambiguity toward recognisable reality.

Do not open with a generic studio-wide lifestyle photograph.

---

## Shop

Default:
**M2 Object Truth**

Rules:
- product still clearly recognizable
- crop can vary slightly but information hierarchy remains stable
- do not make every card an editorial crop
- out-of-stock objects remain visually truthful

Shop is where visual authorship is constrained by evaluation.

---

## Collections

Primary rhythm:

`M2 group/object → M0 material → M2 related forms`

Collections should express a surface family without becoming a theme switch.

A collection needs:
- one reliable object frame
- one material macro
- ideally one grouped still life

Do not simply tint the background to match the collection.

---

## Product Detail

Preferred sequence:

1. **M2 Object Truth**
2. **M0 Material Evidence**
3. **M2 alternate angle / detail**
4. **M3 Object in Use**
5. optional **M1 process relation only when verified**

The first purchase-critical object view stays factual.

Editorial freedom increases after the user has seen the object truth.

---

## Workshops

Preferred sequence:

1. **M1 Action**
2. **M3 Participant**
3. **M1 secondary process**
4. **M2 Outcome**
5. **M3 / M4** studio context

Each workshop should lead with what the hands do.

Examples:

Wheelthrowing:
`Center → Pull → Shape`

Handbuilding:
`Pressure → Join → Form`

Course:
`Handbuild → Wheelthrow → Trim → Glaze`

The visual sequence should follow the real process rather than decorate the labels.

---

## Studio

Preferred sequence:

1. **M4 Field**
2. **M3 Founder**
3. **M1 Founder/teacher working**
4. **M0 material**
5. **M2 finished object**
6. **M4 accumulated studio evidence**

Studio is the only route where the full distance range should appear.

---

## Visit

Preferred:
- M4 exterior / approach
- M4 interior
- practical information

Visit should not use conceptual macro imagery as its primary evidence.

---

## Cart / Booking / Checkout

Image expression contracts.

Cart:
- small M2 object identity only

Booking:
- optional restrained M1/M3 workshop memory

Checkout:
- no visual spectacle required

This preserves **SETTLE WITH INTENT**.

---

# 6. Lighting grammar

Fokhara does not use one universal lighting treatment.

## Object light — SOFT TRUTH

- diffused
- colour accurate
- enough modeling shadow to show curve
- avoid clipped glaze highlights

## Material light — RAKE

- lower angle
- directional
- reveals topography / gloss / edge
- used selectively

## Process light — WORKING LIGHT

- real studio light can stay
- mixed practical environment is acceptable editorially
- skin/clay relationship matters more than perfect neutrality
- do not “luxury grade” all workshop photographs into the same beige tone

## Life light — NATURAL CONTEXT

- believable table / hand / room
- preserve object colour
- avoid props chosen only for trend aesthetics

---

# 7. Colour rules

### Commerce

Product glaze colour must stay as truthful as possible.

No global grade should turn:
- Ocean into teal branding
- Lazuli into generic cobalt
- Latte Foam into beige mood
- Midnight into crushed black

### Editorial

Colour grading may unify contrast/exposure, but not erase collection differences.

### Material states

The website may derive interface accents from real collection identity.

The image itself remains evidence.

---

# 8. Crop grammar

## Object browse crop

- complete silhouette preferred
- breathing room around object
- consistent evaluation
- no random edge clipping

## Object hero crop

- one edge may challenge the frame
- object can become compositional mass
- opening/handle/foot should not be accidentally amputated
- crop must support Carry geometry

## Material crop

- can remove full object identity
- should reveal a real surface event
- should be traceable to an actual object/material source

## Hand crop

- active contact point must be inside the frame
- avoid hands floating without visible clay/action
- fingers may be cropped if the pressure/action remains legible

## Human crop

- activity is the anchor
- faces are not mandatory
- hands/object should not disappear just to achieve portrait beauty

---

# 9. Negative space

Negative space is planned, not found accidentally.

For source requests, ask for some frames with:
- subject offset left
- subject offset right
- subject low in frame
- extra headroom / side room

This gives typography real room without laying text over important craft evidence.

---

# 10. Aspect-ratio guidance

Not every image should be forced into one ratio.

Preferred production families:

- **1:1 / near-square** — object browse / cross-system tiles
- **4:5 portrait** — hands / people / workshop
- **3:2 / 4:3 landscape** — still life / process context
- **16:10 or wider** — studio field / arrival
- **free macro crop** — material evidence

Mobile may use a different crop of the same source.

Never solve mobile by only shrinking the desktop crop.

---

# 11. Motion role

Photography is part of the transition system.

## Carry

Carry prefers **M2 Object Truth** because identity continuity matters.

## Recompose

Destination may:
- expand the same object
- change crop
- reveal an M0 surface detail
- expose an M3 use frame later

## Trace

A prior collection/action can affect:
- crop anchor
- selected alternate image
- material accent
- related visual sequence

It should not add a fake texture layer.

# 14. Reference-gravity guardrail

The references used in VP1 are not composition templates.

We may borrow:
- neutral truth discipline
- raking-light logic
- action-focused crop logic
- still-life spacing principles

We may not copy:
- another ceramic brand’s prop styling
- exact backdrop palette
- exact still-life arrangement
- photographer-specific signature composition
- stock pottery imagery into Fokhara production

The Fokhara system must be authored from its real assets.

---

# 15. VP1 visual thesis refinement

Previous:

> A digital material system where actions leave trace, selected objects causally reform later states, people can cross from observer to maker, and the interface settles from expressive exploration into precise commitment.

Photography refinement:

> **Fokhara moves through distance: material becomes action, action becomes form, form enters a hand, and the hand returns the object to life.**

This is an image-sequence rule, not marketing copy.
