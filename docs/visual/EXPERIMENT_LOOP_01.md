# Fokhara — Experiment Loop 01

This is not a new product phase. It is a disposable visual lab running beside
the accepted product/commerce architecture.

## Why the lab exists

VP10 renders showed that Fokhara already has a coherent system, but coherence
alone can become a premium-editorial template language. The next loop tests
whether the thesis can become visible through authored behavior rather than
more typography, more beige, or decorative motion.

Core rule:

> The web is the medium of execution, not the source of the idea.

And the interaction rule remains:

> Every transition must explain a state change.

## External reality-checks

The current reference pass intentionally happened after Fokhara's own thesis
was established.

- COTTA shows a ceramic practice can hold objects, art, studio culture and
  classes inside one identity rather than looking like a generic pottery shop.
- CaiYawen Ceramics was recognized with scroll and mouse interaction as authored
  elements, useful as evidence that ceramics can carry interaction without
  becoming a game.
- Getty / Resn's Tracing Art uses spatial movement to express real provenance
  relationships. The useful lesson is causal movement, not its visual style.
- Current Awwwards GLSL archives show shaders are common enough to be a mature
  technique library, not a novelty by themselves.
- Kiln uses one interactive glazed 3D cup as a storefront signature. The useful
  lesson is restraint: one meaningful object interaction can carry more identity
  than WebGL everywhere.

None of these is a visual template for Fokhara.

## Experiment candidates

### 01 — Material Memory Field — BUILT IN LAB

Hypothesis:
A digital material field can make **THE FORM REMEMBERS** perceptible before the
visitor reads an explanation.

Mechanic:
- raw WebGL2 fragment shader
- pointer movement leaves a light temporary trace
- press / touch creates a stronger pressure mark
- trace settles and disappears
- no perpetual background animation
- reduced motion becomes static
- real product photography stays completely untouched

Why:
The interface receives the action. The ceramic image does not pretend to deform.

Route:
`/lab/material-memory`

### 02 — Carry Becomes Space

Extend the current carry system, not replace it.

A selected object would lift with a small deterministic depth change based on
real source-to-target distance, carry its material edge into the next route,
then recompose. No generic page fade and no arbitrary spin.

Likely stack:
existing Motion + CSS 3D first; native View Transition as progressive
enhancement where it improves continuity.

### 03 — Kiln Threshold

Workshop/process only.

A finite scroll threshold where the visual field changes from raw/clay to
surface/glaze. It must use factual Fokhara imagery or abstract material state;
never fabricate an exact product transformation without source evidence.

Likely stack:
CSS masks / clip paths first; shader only if the transition needs real surface
behavior.

### 04 — Collection Inheritance

When entering a collection, its material state should survive beyond a simple
background color. The chosen collection can leave a restrained trace in the
next composition and settle only when the user's task changes.

This tests whether collection identity can be *remembered* rather than themed.

### 05 — Studio Contact Sheet

Real studio/process photographs become an authored contact sheet that changes
scale and grouping with the narrative. The goal is to let real Fokhara evidence
break the repeated large-type / neutral-field grammar.

Likely stack:
DOM + CSS + Motion. No WebGL unless evidence proves it adds something.

## Acceptance test for every experiment

Keep it only if all are true:

1. it can be explained using Fokhara's thesis without naming the technology;
2. it makes an action or material relationship clearer;
3. it does not delay Shop / Booking / Cart intent;
4. it works as a finite gesture;
5. reduced motion and mobile still have authored states;
6. removing it would remove meaning, not just spectacle.

If it fails any of those tests, delete it.
