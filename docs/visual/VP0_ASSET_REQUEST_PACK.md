## Why we are asking for multiple image scales

The final visual system needs different kinds of truth:

- **macro** — glaze / clay / hand pressure
- **object** — complete ceramic form
- **human** — maker / participant / use
- **space** — studio / arrival

One product thumbnail cannot do all four jobs.
