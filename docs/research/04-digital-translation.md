# Step 04 — Digital Translation

**Status:** Closed for first Visual Thesis pass  
**Purpose:** Translate the six extracted meaning principles into a usable digital behavior system without yet designing a final page, palette, or visual identity.

---

# Translation Rule

A principle is not a motif.

We are not asking:

> “What does clay look like on a website?”

We are asking:

> “What digital behavior would carry the same relationship, tension, or consequence?”

This distinction is the core of Step 04.

The six meaning principles are:

1. **Becoming**
2. **Retained Trace**
3. **Centered Tension**
4. **Time Is Material**
5. **Material Agency**
6. **Craft Enters Life**

Each principle is translated only into the digital layers where it has real generative power.

No principle must appear everywhere.

---

# 01 — BECOMING → STATEFUL COMPOSITION

## Meaning Carried Forward

The meaningful unit is not the finished state alone.

It is the change between states.

## Digital Translation

### Layout

Layouts should be capable of **re-forming**, not merely revealing.

A composition may:

- begin compressed and gain structure,
- move from one spatial hierarchy to another,
- exchange dominant and supporting elements,
- or transition from ambiguous material to clear product information.

The page should not feel like a stack of finished posters.

It should feel like a system whose arrangement can become more specific as the user moves through it.

### Spacing

Spacing can change with state.

Instead of every section using one repeated rhythm:

- early states may be more open or unresolved,
- later product states can tighten and become functional,
- workshop/process states can widen again to allow gesture and sequence.

The point is not random spacing.

The point is **spatial maturation**.

### Typography

Typography can move from **suggestion → articulation**.

Potential behaviors:

- cropped or partial words becoming complete,
- broad typographic fields resolving into readable hierarchy,
- type scale changing as an idea shifts from emotional to functional,
- short language first, specific information second.

Never sacrifice readability to “formation.”

### Imagery

Images should not always arrive as fully framed editorial cards.

Possible translation:

- fragments establish material or gesture before the full object appears,
- process and finished object can be connected through continuity,
- crop relationships can evolve,
- a finished product can emerge from context rather than appear as an isolated tile.

### Motion

Motion should express **state change**, not permanent ambient movement.

Preferred motion categories:

- assemble,
- resolve,
- expand,
- compress,
- reveal structure,
- transfer emphasis,
- transition from process to object.

Avoid continuous decorative spinning.

### Navigation

Navigation may support the idea of progression between different forms of engagement:

**Discover → Make → Learn → Own / Use**

But navigation labels must remain product-clear.

The metaphor must not override usability.

### Transitions

Page transitions are one of the strongest surfaces for Becoming.

A transition should carry an element, state, crop, title, or object relationship from one context into the next rather than blanking the screen and restarting.

The important behavior is:

**state A contains the seed of state B.**

### Product Presentation

Product detail should reveal a ceramic as:

**object + evidence of making + use**

not only:

**hero image + price + button**

The finished piece is the current state of a longer process.

# 02 — RETAINED TRACE → CAUSAL MEMORY

## Meaning Carried Forward

Actions leave evidence.

The system may remember what happened earlier and let that memory alter what appears later.

## Digital Translation

### Interaction

This principle should live primarily in interaction state.

Examples of valid translation:

- an image crop influenced by what the user previously focused on,
- a process marker remaining subtly present after a transition,
- a visited workshop or product leaving a meaningful visual state,
- interaction history affecting a later composition within the same session,
- an element carrying a position or scale relationship across navigation.

The trace must have a cause the user can understand, even subconsciously.

### Motion

Motion can leave a residual state rather than resetting perfectly.

Examples:

- a title does not return to its exact initial arrangement after engagement,
- an image remains slightly displaced because it was the object carried into the next view,
- a transition preserves orientation or scale from the previous page.

### Visual Surface

Do not simulate handmade texture with fake noise.

If a mark appears, it should correspond to:

- interaction,
- process,
- material evidence,
- photography,
- or real production detail.

### Product Cards

Repeated card templates can preserve consistency while allowing **real source variation** from:

- actual object silhouette,
- actual glaze,
- actual crop,
- actual process category,
- actual dimensions.

The “handmade” feeling should come from content truth, not random card distortion.

### Session Memory

A lightweight session memory may be appropriate later:

- recently explored making processes,
- products viewed,
- workshop path entered.

But this should improve continuity, not become a gimmick.

### Guardrail

No:
- random rotations,
- random border radii,
- random offsets,
- procedural fingerprints,
- fake scratches,
- noise overlays with no source.

Retained Trace means **causal persistence**.

# 03 — CENTERED TENSION → STRUCTURED ASYMMETRY

## Meaning Carried Forward

Stable form comes from forces being brought into relationship.

The visual system should feel controlled, not sterile.

## Digital Translation

### Grid

Use a strong underlying grid, but allow compositions to pull against it.

A good Fokhara composition may contain:

- one stable structural axis,
- one intentionally displaced image mass,
- one opposing typographic mass,
- controlled overlap,
- or unequal visual weights that still resolve.

The target is **structured asymmetry**.

Not chaos.

Not perfect symmetry.

### Spacing

Spacing should create pressure and release.

Possible rhythm:

**tight cluster → open field → contact → release**

This can produce a tactile sense without illustrating clay.

### Alignment

Not everything should center.

Instead, every composition should have a perceivable **center of gravity**.

That center may be:

- visual,
- semantic,
- spatial,
- or interactive.

### Typography

Typography can carry tension through:

- large display scale against restrained body copy,
- compact text blocks inside large negative space,
- strong line breaks,
- deliberate edge proximity,
- opposing alignments that still share a system.

Avoid expressive distortion that damages reading.

### Image Composition

Objects may sit near an edge, partially exceed a frame, or oppose a text block, but should feel intentionally counterbalanced.

The product should feel physically present, not dropped into a template.

### Motion

Motion should have:

- acceleration,
- resistance,
- settling,
- counter-motion,
- controlled overshoot only where meaningful.

It should not feel frictionless or mechanically linear.

### Navigation

Navigation should remain stable.

The expressive tension belongs around it, not inside basic wayfinding.

Primary navigation is an anchor.

### Guardrail

Centered Tension is **not**:
- center-align everything,
- wobble everything,
- asymmetric for the sake of looking editorial,
- or make controls difficult to find.

# 04 — TIME IS MATERIAL → PACING, SEQUENCE, THRESHOLDS

## Meaning Carried Forward

Time participates in transformation.

The digital equivalent is not delay.

It is sequence, consequence, and threshold.

## Digital Translation

### Scroll

Scroll can reveal changes that depend on progression.

Good uses:

- a process becomes legible over several beats,
- a material state changes as context accumulates,
- one visual condition prepares the next,
- information appears when its meaning has been established.

Bad use:

- forcing users through long cinematic scroll before they can shop or book.

### Motion Duration

Motion should be **variable by meaning**, not globally slow.

- navigation feedback: immediate,
- product interactions: responsive,
- narrative transitions: allowed more breathing room,
- irreversible actions: clear and decisive.

### Thresholds

Important digital moments can behave as thresholds:

- entering a workshop path,
- moving from exploration to booking,
- selecting a product variant,
- adding to cart,
- committing to checkout.

The interface should make state change clear.

### Progressive Disclosure

Information can arrive in stages:

**emotion → understanding → specifics → action**

This is especially useful for workshops.

Do not show every detail in the first visual frame.

But do not hide critical purchase information.

### Page Rhythm

A page can alternate:

**formation → pause → resolution**

rather than repeating equally sized sections.

### Guardrail

Time Is Material does not permit:
- artificial loaders,
- scroll-jacking,
- delayed CTAs,
- locked content,
- long unskippable animations.

# 05 — MATERIAL AGENCY → RESPONSIVE RESISTANCE

## Meaning Carried Forward

The user acts on the system, and the system responds with character.

The relationship is not command → dead output.

## Digital Translation

### Pointer / Touch Behavior

Interactive objects may respond with subtle physical logic:

- slight resistance,
- delayed settling,
- constrained displacement,
- edge attraction,
- pressure-like deformation where technically appropriate.

But all interaction targets remain predictable.

### Hover

Hover should reveal **response**, not simply decoration.

Examples:

- an image changes crop because attention is applied,
- object information moves into a more resolved state,
- a surface exposes process evidence,
- a card shifts hierarchy rather than just changing color.

### Drag / Gesture

If drag is used, it must have a product reason.

Possible later use:

- inspecting forms,
- comparing stages,
- browsing a process sequence.

Do not add drag just to prove technical sophistication.

### Motion Physics

Prefer motion that suggests:
- inertia,
- resistance,
- settling,
- constraint,
- balance.

Avoid zero-friction floating interfaces.

### Responsive Layout

Material Agency also applies across screen sizes.

The system should **recompose**, not merely shrink.

Mobile should have its own balance and rhythm.

### Guardrail

The interface must never become unpredictable.

The user should feel that the system has behavior, not that it has bugs.

# 06 — CRAFT ENTERS LIFE → PRODUCT-FIRST HUMAN CONTEXT

## Meaning Carried Forward

Fokhara's craft is made to be experienced, used, learned, bought, booked, and lived with.

This principle protects the project from becoming a portfolio experiment.

## Digital Translation

### Product Photography

Ceramics should appear in at least two realities:

1. **Object reality** — form, glaze, detail, dimensions.
2. **Life reality** — held, used, placed, poured into, shared, or lived beside.

Neither should fully replace the other.

### Workshop Presentation

Workshops should not be presented as generic event cards.

Their content hierarchy should make clear:

- what the person will do,
- what skill level is expected,
- what material/process they will encounter,
- duration,
- format,
- availability,
- price,
- and what they leave with.

The emotional promise and practical commitment must coexist.

### Commerce

Commerce flows must remain direct.

Art direction may shape context but not obstruct:

- price,
- variant,
- availability,
- add to cart,
- booking,
- schedule,
- location,
- checkout.

### Story

The story should connect the studio, maker, process, and everyday object.

Avoid a long “About Us” essay as the only place where meaning lives.

The meaning should be distributed through the experience.

### Content Density

Not every surface should be sparse.

Functional moments can become denser.

This contrast is desirable:

**wide emotional field → concentrated useful information**

### Guardrail

If a user admires the site but cannot quickly understand what Fokhara sells or how to participate, the design has failed.

# Cross-System Translation

The six principles now combine into a digital grammar.

---

## A. SPACE

### Rule

**Wide fields + concentrated pressure points.**

Why:

- Centered Tension creates pressure/release.
- Becoming allows density to evolve.
- Craft Enters Life permits functional compression where needed.

### Implication

Avoid a site made entirely of equally spaced centered sections.

Prefer changing spatial states.

---

## B. GRID

### Rule

**Stable underlying system, visibly challenged but rarely broken.**

Why:

- centering requires structure,
- tension requires opposing force,
- trace requires continuity.

### Implication

The grid is a hidden wheel axis, not a cage.

No need to literally draw radial grids.

---

## C. TYPOGRAPHY

### Rule

**Calm authority with moments of physical scale.**

Typography should feel:

- crafted,
- deliberate,
- readable,
- contemporary,
- not “rustic.”

Potential direction:

- one strong display voice,
- one highly legible utility/body voice,
- contrast through scale and spacing rather than decorative type effects.

### Behavior

Type may change hierarchy across states, but never become materially illegible.

### Forbidden

- faux-handwritten craft fonts as primary identity,
- Egyptian novelty fonts,
- distressed type to fake handmade character.

---

## D. IMAGERY

### Rule

**Object + process + human use.**

The image system should carry three scales:

1. **macro** — hands, clay, tools, glaze, surface, pressure.
2. **object** — the complete ceramic form.
3. **life** — object in use / person making / studio context.

### Behavior

Crops can transition between scales.

A detail may become an object.

An object may become a lived scene.

This is a direct translation of Becoming.

---

## E. MOTION

### Rule

**Motion happens because a state is changing.**

Core motion verbs:

- form,
- gather,
- compress,
- release,
- carry,
- settle,
- resolve,
- transfer,
- reveal,
- commit.

### Physics

- responsive,
- weighted,
- controlled,
- occasionally resistant,
- capable of settling.

### Forbidden

- perpetual rotation,
- decorative liquid blobs,
- endless floating,
- generic parallax everywhere,
- cinematic delays on basic actions.

---

## F. INTERACTION

### Rule

**Cause should leave consequence.**

A meaningful interaction should alter:
- hierarchy,
- state,
- continuity,
- memory,
- or context.

Do not create effects that disappear without meaning.

---

## G. NAVIGATION

### Rule

**Navigation is the stable center.**

The expressive system can transform around it.

Navigation should answer quickly:

- Shop
- Workshops / Courses
- Studio / Story
- practical access such as Cart / Booking / Visit as required by product architecture.

Exact information architecture is deferred to Product Architecture.

### Behavior

Navigation transitions may preserve context, but labels and routes must remain obvious.

---

## H. PAGE TRANSITIONS

### Rule

**Carry, do not erase.**

A good transition should preserve something meaningful:

- object,
- crop,
- title,
- spatial axis,
- interaction state,
- or process relationship.

The next page should feel formed from the previous one when context exists.

A hard cut is still allowed when it has semantic value.

---

## I. PRODUCT CARDS

### Rule

**Consistent structure, source-driven individuality.**

Variation should come from:
- actual product form,
- actual photography,
- actual glaze,
- actual scale,
- actual collection/content.

Not randomized UI geometry.

Cards should remain scannable and commerce-ready.

---

## J. PRODUCT DETAIL

### Rule

**Finished object + trace of becoming + practical use.**

Potential content sequence:

1. immediate object recognition,
2. price / availability / action,
3. physical detail,
4. process or material evidence,
5. scale/use context,
6. related pieces / collection.

Do not bury purchase controls under storytelling.

---

## K. WORKSHOP DETAIL

### Rule

**Invitation + process + commitment.**

Potential sequence:

1. what experience is this?
2. what will I physically do?
3. who is it for?
4. what will I learn/make?
5. time/date/duration,
6. price/availability,
7. book.

This surface can express Becoming especially strongly because the visitor becomes the maker.

---

## L. MOBILE

### Rule

**Recompose, never merely shrink.**

Mobile should preserve:
- strong center of gravity,
- meaningful state transitions,
- image scale,
- direct commerce,
- readable type,
- thumb-safe action.

Complex carry transitions can simplify on mobile without losing their semantic relationship.

The concept must survive reduced spectacle.

# Interaction Physics Vocabulary

This is not a final animation specification.

It is the approved behavior vocabulary for future prototypes.

## Allowed / Promising

- weighted settling
- constrained displacement
- controlled compression
- expansion from a clear origin
- carry-over continuity
- scale transfer
- crop transformation
- delayed consequence after a prior action
- accumulated layer reveal
- state locking at meaningful thresholds
- subtle inertial response

## Use With Caution

- morphing
- distortion
- rotation
- blur
- mask animation
- cursor-reactive surfaces
- drag
- depth/parallax
- shader effects

These are techniques, not concepts.

They are accepted only if they express one of the six principles.

## Rejected as Default Language

- random wobble
- looping wheel rotation
- liquid blob UI
- fake clay deformation everywhere
- texture noise overlays
- cracked-screen motifs
- kiln/fire transitions
- “ancient Egypt” visual shorthand
- gratuitous 3D product spinning
- sluggish scroll as craft metaphor

---

# Content Behavior

The content system should mirror the same philosophy.

## Copy

Use fewer, more specific statements.

Avoid explaining the entire ceramic philosophy in prose.

The interface should carry much of the meaning.

Copy should primarily do four jobs:

1. identify,
2. clarify,
3. invite,
4. enable action.

## Storytelling

Meaning should be distributed.

Instead of one huge brand manifesto, use:
- short process notes,
- material facts,
- workshop actions,
- product context,
- maker voice,
- real object detail.

## Product Language

Prefer concrete language:
- material,
- dimensions,
- process,
- use,
- collection,
- care,
- availability.

Avoid generic luxury language such as:
- timeless,
- elevated,
- artisanal excellence,
- crafted with passion,

unless Fokhara itself has a specific reason to use it.

# First System-Level Hypothesis

Without designing the final visual thesis yet, the digital system now appears to want this behavior:

> **A stable interface that repeatedly reforms around real objects and actions, preserving traces between states, using controlled tension and weighted motion, while becoming increasingly practical as the user moves from discovery toward making, booking, owning, and using.**

This is a behavior hypothesis.

It is not a homepage concept.

It is not final art direction.

# Step 04 Exit Test

Digital Translation is complete when we can reject a visual idea before seeing whether it “looks cool.”

Examples:

### “Make every product card slightly crooked.”
Reject.
No causal trace.

### “Carry the selected product image into its detail page and let the detail layout resolve around it.”
Keep for Visual Thesis exploration.
Expresses Becoming + Retained Trace.

### “Make the whole homepage rotate like a pottery wheel.”
Reject.
Literal source mimicry.

### “Use one stable compositional axis while image mass and type pull against it.”
Keep for exploration.
Expresses Centered Tension.

### “Make scroll intentionally heavy and slow.”
Reject.
Confuses time with latency.

### “Let workshop storytelling progress from raw material to participant action to clear booking commitment.”
Keep.
Expresses Becoming + Time + Craft Enters Life.

# Step 04 Exit Condition

We now have a digital grammar but not a visual composition.

The next step is **Step 05 — First Visual Thesis**.

That step should combine the grammar into a coherent first design world:

- spatial character,
- visual hierarchy,
- art-direction stance,
- typography direction,
- image choreography,
- signature interaction ideas,
- page-level composition hypotheses.

Still **without opening award-site references first**.

Only after the first authored Visual Thesis exists should the project enter a Web Reality Check.
